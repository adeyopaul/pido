# Pido

A fintech-style mobile application UI built with Flutter as a personal learning and demo project.

> **Project status:** Learning/demo project — not a production fintech application.

## 📱 Overview

Pido was created to practise building a polished fintech-style mobile experience with Flutter. The project focuses primarily on mobile UI implementation, responsive layouts, navigation, reusable widgets, and Flutter project structure.

## ✨ Features

- Splash screen
- Onboarding
- Login and registration
- Home dashboard
- Wallet
- Transfers
- Transaction history
- Profile
- Settings
- Bill payments

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **flutter_screenutil** — responsive sizing and layout
- **flutter_svg** — SVG asset support
- **font_awesome_flutter** — icons
- **flutter_native_splash** — native splash screen
- **fluttertoast** — user feedback

## 🧩 Project Structure

The application is organised around separate core, presentation, and routing areas:

```text
lib/
├── core/
├── presentation/
├── routes/
└── main.dart
```

## 🎯 What I Practised

- Translating fintech-style designs into Flutter interfaces
- Building responsive mobile layouts
- Creating reusable Flutter widgets
- Structuring a Flutter application
- Working with navigation and routes
- Managing application assets
- Creating and configuring native splash screens
- Building consistent UI across different screen sizes
